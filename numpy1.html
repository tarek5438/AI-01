⚡ المرجع السريع لجميع دوال الدرسين (Cheat Sheet)

جدول مقارنة شامل للدوال وسلوك المحاور
الدالة البرمجية الدرس الوظيفة الأساسية السلوك مع axis=0 (رأسي ↓) السلوك مع axis=1 (أفقي ←)
np.concatenate((a, b)) الدرس 8 دمج مصفوفتين أو أكثر معًا إضافة صفوف جديدة أسفل بعضها (الافتراضي) إضافة أعمدة جديدة بجانب بعضها
np.vstack((a, b)) الدرس 8 تكديس رأسي (Vertical Stack) يضع مصفوفة فوق أخرى رأسيًا (يحول 1D إلى 2D، ويكافئ دمج الصفوف لإضافة Samples)
np.hstack((a, b)) الدرس 8 تكديس أفقي (Horizontal Stack) يضع مصفوفة بجانب أخرى أفقيًا (في 1D يدمجها في صف واحد، وفي 2D يضيف أعمدة Features)
np.split(arr, n_or_idx) الدرس 8 تقسيم مصفوفة إلى عدة أجزاء تقسيم الصفوف رأسيًا إلى مجموعات (الافتراضي) تقسيم الأعمدة أفقيًا إلى مجموعات
np.mean(data) الدرس 10 المتوسط الحسابي (مجموع القيم ÷ عددها) متوسط كل عمود (Feature) على حدة متوسط كل صف (Sample) على حدة
np.median(data) الدرس 10 الوسيط (القيمة الوسطى بعد الترتيب، مقاوم للقيم الشاذة) وسيط كل عمود على حدة وسيط كل صف على حدة
np.min() / np.max() / np.sum() الدرس 10 أصغر قيمة / أكبر قيمة / مجموع العناصر أصغر/أكبر/مجموع كل عمود أصغر/أكبر/مجموع كل صف
np.std() / np.var() الدرس 10 الانحراف المعياري والتباين (STD = √Var) تشتت كل عمود (Feature) حول متوسطه تشتت قيم كل صف حول متوسطه

Combining & Splitting Arrays — دمج وتقسيم المصفوفات

شرح تفصيلي مدعوم بالأمثلة الكاملة لدمج المصفوفات عبر np.concatenate() و np.vstack() و np.hstack()، وتقسيمها بواسطة np.split() مع فهم عميق لـ axis.

1

لماذا نحتاج دمج المصفوفات؟ و np.concatenate()

تخيل أن لدينا درجات طلاب مقسمة على مجموعتين students1 و students2 ونريد جمعها في مصفوفة واحدة متتالية. أبسط طريقة هي np.concatenate((arr1, arr2)) وتعني: ضع المصفوفات وراء بعضها.

Python — دمج مصفوفتين 1D 
import numpy as np

arr1 = np.array([10, 20, 30])
arr2 = np.array([40, 50, 60])

result = np.concatenate((arr1, arr2))
print(result)
# الناتج: [10 20 30 40 50 60]
💡 ملاحظة هامة: نمرر المصفوفات داخل زوج إضافي من الأقواس ((arr1, arr2)) كـ Tuple، ويمكننا دمج 3 مصفوفات أو أكثر بنفس الطريقة!
2

دمج 3 مصفوفات أو مصفوفات ثنائية الأبعاد (2D Arrays)

عند دمج 3 مصفوفات أحادية توضع جميعها بالتتابع، أما عند دمج مصفوفتين ثنائيتي الأبعاد (2D) بدون تحديد المحور، فإنها تدمج الصفوف تحت بعضها تلقائيًا:

Python — دمج 3 مصفوفات ودمج 2D 
# مثال 1: دمج ثلاث مصفوفات
a = np.array([1, 2])
b = np.array([3, 4])
c = np.array([5, 6])
print(np.concatenate((a, b, c))) # [1 2 3 4 5 6]

# مثال 2: دمج مصفوفتين ثنائيتي الأبعاد (2D)
arr1 = np.array([[1, 2], [3, 4]])
arr2 = np.array([[5, 6], [7, 8]])
result = np.concatenate((arr1, arr2))
# الناتج:
# [[1 2]
#  [3 4]
#  [5 6]
#  [7 8]]
3

الفهم العميق للمحاور (axis=0 مقابل axis=1) وأهميتها في الذكاء الاصطناعي (AI)

مفهوم جوهري في Data Science
المحور الرأسي: axis = 0 ↓ إضافة صفوف / Samples

يمثل الاتجاه الرأسي (الصفوف تتغير ونتحرك للأسفل). عند استخدام np.concatenate((arr1, arr2), axis=0) توضع صفوف المصفوفة الثانية أسفل صفوف المصفوفة الأولى.

arr1 (2,2) + arr2 (2,2) [axis=0] ➔ Result (4,2)
[[1, 2],
[3, 4],
[5, 6],
[7, 8]]
🤖 في الذكاء الاصطناعي: لو لديك Dataset بحجم (1000, 5) (ألف طالب × 5 خصائص) ووصلت دفعة جديدة بحجم (500, 5)، ندمجهما بـ axis=0 لتصبح (1500, 5).
المحور الأفقي: axis = 1 ← إضافة أعمدة / Features

يمثل الاتجاه الأفقي (الأعمدة تتغير ونتحرك أفقيًا). عند استخدام np.concatenate((arr1, arr2), axis=1) توضع أعمدة المصفوفة الثانية بجانب أعمدة المصفوفة الأولى.

arr1 (2,2) + arr2 (2,2) [axis=1] ➔ Result (2,4)
[[1, 2, | 5, 6],
[3, 4, | 7, 8]]
🤖 في الذكاء الاصطناعي: لو لديك Dataset بحجم (1000, 5) وأردت إضافة خاصيتين جديدتين لكل الطلاب بحجم (1000, 2)، ندمجهما بـ axis=1 لتصبح (1000, 7).
4

التكديس الرأسي np.vstack() مقابل الأفقي np.hstack()

بدلًا من كتابة axis=0 أو axis=1، توفر NumPy دوال صريحة ومباشرة:

1. دالة np.vstack((a, b)) — Vertical Stack (فوق بعض ↓):

تضع المصفوفة الأولى فوق الثانية. انتبه: إذا مررت لها مصفوفتين أحاديتين 1D مثل [1, 2, 3] و [4, 5, 6] فإنها تحولهما إلى مصفوفة ثنائية 2D بحجم (2, 3): [[1, 2, 3], [4, 5, 6]]. تُستخدم عند إضافة Rows / Samples.

2. دالة np.hstack((a, b)) — Horizontal Stack (بجانب بعض ←):

تضع المصفوفات بجانب بعضها أفقياً. مع 1D تبقى 1D: [1, 2, 3, 4, 5, 6]، ومع 2D تضيف الأعمدة بجانب بعضها. تُستخدم عند إضافة Columns / Features (مثل دمج عمود العمر age مع عمود الراتب salary).

Python — مثال إضافة Features (العمر والراتب) 
age = np.array([[20], [25], [30]])       # Shape: (3, 1)
salary = np.array([[5000], [7000], [9000]]) # Shape: (3, 1)

data = np.hstack((age, salary))
print(data)
# [[  20 5000]
#  [  25 7000]
#  [  30 9000]]
print(data.shape) # (3, 2) -> 3 Samples, 2 Features
5

تقسيم المصفوفات باستخدام np.split()

عملية عكس الدمج تمامًا، وتُستخدم لتقسيم مصفوفة كبيرة إلى عدة مصفوفات فرعية بثلاث طرق رئيسية:

✅ 1. التقسيم إلى n أجزاء متساوية: np.split(arr, 3) يقسم مصفوفة من 6 عناصر إلى 3 مصفوفات في كل منها عنصران (6 ÷ 3 = 2).
⚠️ شرط مهم جدًا: يجب أن يقبل عدد العناصر القسمة على n، وإلا سيحدث Error (مثلاً np.split([1,2,3,4,5], 3) يعطي خطأ لأن 5 لا تقبل القسمة على 3).
✂️ 2. تحديد فهارس (Indices) القطع: np.split(arr, [2, 4]) يقطع المصفوفة قبل الفهرس 2 وقبل الفهرس 4: [10, 20 | 30, 40 | 50, 60].
🧭 3. تقسيم مصفوفة 2D مع axis: افتراضيًا (axis=0) يقسم الصفوف، ومع np.split(arr, 2, axis=1) يقسم الأعمدة (مصفوفة (2, 4) تنقسم إلى مصفوفتين كل منهما (2, 2)).
Python — جميع حالات np.split() 
arr = np.array([10, 20, 30, 40, 50, 60])
print(np.split(arr, 3))      # [array([10, 20]), array([30, 40]), array([50, 60])]
print(np.split(arr, [2, 4])) # نفس الناتج بالقطع عند الفهرس 2 و 4

mat = np.array([[1, 2, 3, 4], [5, 6, 7, 8]]) # Shape: (2, 4)
parts = np.split(mat, 2, axis=1) # يقسم الأعمدة إلى جزأين (2, 2)

Statistical Functions in NumPy — الدوال الإحصائية

شرح شامل لدوال التحليل الإحصائي mean و median و min و max و sum و std و var وكيفية توظيفها مع axis=0 و axis=1.

1

المتوسط الحسابي np.mean() والوسيط np.median()

🔹 المتوسط الحسابي (np.mean): يساوي مجموع القيم مقسومًا على عددها. ففي درجات الطلاب [80, 90, 70, 60, 95] المجموع هو 395، والمتوسط 395 ÷ 5 = 79.0.

🔹 الوسيط (np.median): هو القيمة التي تقع في المنتصف تمامًا بعد ترتيب البيانات:

  • إذا كان عدد العناصر فرديًا مثل [10, 20, 30, 40, 50] يأخذ الرقم الأوسط مباشرة وهو 30.0.
  • إذا كان عدد العناصر زوجيًا مثل [10, 20, 30, 40] يأخذ العنصرين الأوسطين (20 و 30) ويحسب متوسطهما: (20 + 30) / 2 = 25.0.
Python — الفرق الجوهري عند وجود قيمة شاذة (Outlier) 
arr = np.array([10, 20, 30, 40, 1000])

print(np.mean(arr))   # 220.0 (تأثر بشدة بالرقم 1000)
print(np.median(arr)) # 30.0  (لم يتأثر بالقيمة المتطرفة!)
2

الانحراف المعياري np.std() والتباين np.var()

بالإضافة إلى np.min() (أصغر قيمة) و np.max() (أكبر قيمة) و np.sum() (المجموع)، نحتاج في الذكاء الاصطناعي إلى قياس مدى انتشار وتشتت القيم حول المتوسط:

انحراف معياري صغير (STD صغير):

يعني أن القيم متقاربة جدًا من المتوسط (مثل أعمار الطلاب [20, 21, 22, 23, 24]). وإذا كانت القيم متطابقة [50, 50, 50] يكون STD = 0.0.

انحراف معياري كبير (STD كبير):

يعني أن القيم متباعدة ومنتشرة بشدة (مثل الرواتب [3000, 5000, 15000, 30000, 80000]).

🔗 العلاقة الرياضية الذهبية: الانحراف المعياري يساوي الجذر التربيعي للتباين: STD = √Variance | Variance = STD²
Python — مثال Variance = 200 ➔ STD ≈ 14.14 
arr = np.array([10, 20, 30, 40, 50])
print("Variance:", np.var(arr)) # 200.0
print("STD:", np.std(arr))      # 14.1421356... (لأن √200 ≈ 14.14)
3

استخدام axis=0 و axis=1 مع الدوال الإحصائية في Dataset حقيقية

عند تطبيق أي دالة إحصائية (mean, median, min, max, sum, std, var) على مصفوفة ثنائية الأبعاد:

1. بدون axis (الافتراضي)
np.mean(data)

يحسب الإحصائية لجميع عناصر المصفوفة بالكامل ويعيد رقمًا واحدًا فقط (مجموع الـ 9 عناصر ÷ 9).

2. مع axis=0 (لكل عمود ↓)
np.mean(data, axis=0)

يجري العملية على مستوى الأعمدة / Features؛ فيعطيك متوسط العمر، ومتوسط الساعات، ومتوسط الدرجة.

3. مع axis=1 (لكل صف ←)
np.mean(data, axis=1)

يجري العملية على مستوى الصفوف / Samples؛ فيعطيك نتيجة مستقلة لكل طالب أو سجل.

Python — المثال الشامل لتحليل Dataset طلاب (5 طلاب × 3 خصائص: Age, Hours_Study, Score) 
import numpy as np

# الأعمدة: [Age, Hours_Study, Score]
data = np.array([
    [15, 2, 70],
    [16, 3, 80],
    [17, 5, 95],
    [15, 1, 60],
    [16, 4, 85]
])

print("Shape:", data.shape)                 # (5, 3) -> 5 Students, 3 Features
print("Mean per Feature:", np.mean(data, axis=0))   # [15.8  3.  78. ]
print("Median per Feature:", np.median(data, axis=0)) # [16.   3.  80. ]
print("Min per Feature:", np.min(data, axis=0))     # [15  1 60]
print("Max per Feature:", np.max(data, axis=0))     # [17  5 95]
print("STD per Feature:", np.std(data, axis=0))     # [0.748  1.414 12.083]
